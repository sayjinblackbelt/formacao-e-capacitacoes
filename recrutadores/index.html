05 / IA, Dados & Streaming

Arquitetura antes do hype.

Da IA aos dados em movimento

O portfólio combina IA assistida, agentes especializados, análise determinística e, mais recentemente, arquitetura orientada a eventos e streaming.

PostgreSQL → CDC → Kafka → Schema Registry → Flink SQL → fraud-alerts → Consumer Documentos → regras → IA → JSON → histórico Educação → agentes especializados → aprendizagem Dados financeiros → regras → insights → agente
Ver pipeline de streaming →

Princípios técnicos

• separar cálculo determinístico de interpretação de IA

• usar eventos e streaming quando o problema exige dados em movimento

• documentar limites, evidências e roadmap

• não inventar dados ou experiências

• considerar segurança, privacidade e reprocessamento
